# 観葉植物お試し配置サービス MVP v3

## v3修正内容

- 植物カードを画像主導UIに変更
- 樹高目安を追加
- 成長タイプを追加
- 診断結果にも植物名・樹高・成長タイプを表示
- 既存の写真アップロード、写真ズーム、植物ドラッグ、サイズ調整、光環境診断は維持

assetsフォルダの4枚画像はそのままでOKです。
